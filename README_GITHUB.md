
## ✨ Features

### 🔐 Role-Based Access Control
- **Students** - Browse events, register, view certificates
- **Faculty** - Create events, manage users, issue certificates
- **Admin** - Full system control, user management, analytics

### 📅 Event Management
- Create and manage campus events
- Event approval workflow
- Participant registration (individual/team)
- Attendance tracking
- Featured events control

### 👥 User Management
- View all registered users
- Search and filter capabilities
- User activity tracking
- Delete user controls (Faculty/Admin)

### 📊 Analytics & Tracking
- Event participation statistics
- Department-wise breakdown
- Attendance rates
- User activity history

### 🎨 Modern UI/UX
- Smooth animations and transitions
- Responsive design
- Gradient effects
- Interactive components

## 🚀 Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, shadcn/ui
- **State Management**: React Context
- **Routing**: React Router
- **PDF Generation**: jsPDF
- **QR Codes**: qrcode library
- **Build Tool**: Vite

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/campus-connect.git

# Navigate to project
cd campus-connect

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🔧 Configuration

The app uses local storage for data persistence. No backend setup required for development.

## 📱 Usage

### For Students:
1. Sign up with college email (@klh.edu.in)
2. Browse and register for events
3. View participation history
4. Download certificates

### For Faculty/Admin:
1. Sign up with any email
2. Create and manage events
3. Approve event registrations
4. Issue certificates to participants
5. Manage users and view analytics
